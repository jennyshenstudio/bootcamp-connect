## 2026-10-09 (end of session: Connect and profile, version 1)
- **What changed:** worked out with the owner how members find each other, how connecting works and what the profile is for, using LinkedIn "People you may know", YC Co-Founder Matching, CoffeeSpace, Lunchclub, Bumble Bizz, Peerlist, Handshake, Wellfound, dev.to, GitHub and JSON Resume as examples. Sample members, posts and chats moved to the UK. `/code-review` found 10 problems, all fixed with tests. 260 tests pass, on the source and the built site. Shared prototype republished (version 20).
- **What's next:** next session (2026-10-10) starts with the owner trying Connect and the profile on the prototype and listing tweaks for version 2. On the published page, check whether "Suggest from code link" can read a GitHub repository; if not, the paste box takes over, as designed.
- **Open questions:** ideas for version 2: Claude writing a short "why you two" line; a JSON Resume download on the live site; checking workplaces and schools by email (live site). Before the live site collects them, the privacy notice and `docs/personal-data.md` must list cohort, education, screenshots, links and teammates. Showing members to each other on the live site needs D034 step 2 (online safety) first.
- **Worth learning:** made-up data generated by a script with a fixed starting value is the same every run, and a test that reruns the script and compares catches anyone editing the output by hand.
